# Aturan Project MBG
Stack: Next.js (App Router) + TypeScript + Tailwind + PostgreSQL (Docker), library `pg`.
Folder: src/app, src/components, src/lib, src/types, db/init.
Tampilan: tablet/PC dulu, putih bersih, kartu kaca putih, simple, tanpa ungu, 1 CTA per layar, minim kata.
Database: snake_case, semua tabel punya kitchen_id (siap banyak dapur). Perubahan skema ditulis ke db/init.
Kerja per langkah kecil. Revisi: sebut dan kirim hanya file yang berubah.
Peran: ahli_gizi, kepala_dapur, kurir, owner, admin_yayasan.
